## Produktionstipps

- **Einstieg:** In den ersten zwei Takten nur Kick und Vocal, Hi-Hats erst danach. So bleibt Steigerung, obwohl der Song ohne Intro startet.
- **Sidechain:** Starke Sidechain-Kompression auf Bass und Pads, damit alles „pumpt“.
- **Vocal-Hook:** Pitchen und choppen, dann als Lead-Instrument im Drop einsetzen.
- **Groove:** Kurze, trockene Percussion (Shaker, Rimshots).
- **Drop-Wirkung:** Vor dem Drop einen Takt komplett Stille, das sorgt für den maximalen Knall.
- **Social Media:** Der Drop bei 0:30 eignet sich gut als 15-Sekunden-Clip für Reels und TikTok.
